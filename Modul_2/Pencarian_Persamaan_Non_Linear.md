# Modul	2:	Pencarian	Akar Persamaan	Non-Linear dengan	metode Bisection,	Newton-Raphson,	dan	Secant	
## A. Tujuan:	
  ```bash
     Praktikum	ini	dilakukan	dengan	tujuan:	
      1. Memahami	konsep	metode	iteratif	
      2. Memahami	prinsip	dasar	dari	metode	Bisection,	Newton-Raphson,	dan	
         Secant	untuk	pencarian	akar	persamaan	non-linear	
      3. Menganalisis	eisiensi	dan	akurasi	ketiga	metode	tersebut
  ```

## B. Kompetensi	yang	diharapkan:		
```bash
    Setelah	mengikuti	praktikum	ini,	diharapkan	mahasiswa	mampu:	
    1. Membandingkan	ketiga	metode	dari	segi	laju	konvergensi	(kecepatan mencapai	akar), akurasi	hasil,
       dan	syarat-syarat	yang	diperlukan	(misalnya, kebutuhan	akan	turunan	atau	selang).	
    2. Mengidenti ikasi	dan	memilih	metode	pencarian	akar	yang	paling	optimal	berdasarkan	karakteristik
       persamaan	(misalnya,	apakah	fungsi	mudah	diturunkan,	atau	apakah	tebakan	awal	dapat	ditentukan).
  ```

## C. Perintah	Soal:	
```bash
    1. Buat	program	Python	untuk	mencari	akar	persamaan	berikut:	
        Χ +Χ −3Χ−3	=	0
       dengan	metode	Bisection,	Newton-Raphson,	dan	Secant.
       Sertakan	juga visualisasi	grafik	dan	waktu	eksekusinya.	
    2. Bandingkan	laju	konvergensi	(kecepatan	mencapai	akar),	akurasi	hasil,
       dan	syarat-syarat	yang	diperlukan	(misalnya,	kebutuhan	akan	turunan	atau selang)
       ketiga	metode	tersebut.	
  ```

## E. Dasar	Teori
```bash
    1. Metode	Bisection	
    2. Metode	Newton-Raphson	
    3. Metode	Secant
```
